Capabilities statement

Measurement instrumentation for AI systems

Antagon builds the instruments that establish whether an AI system behaves as claimed — scored against a computable optimum rather than a rubric, with the methodology stated and the results reproducible.

What we do

And what we don't

Most AI evaluation reports whether a system passed. That answers a different question from the one a programme office actually has, which is whether the reported number supports the conclusion being drawn from it.

Our work is measurement validity: building environments where the correct outcome is computed exactly, scoring behaviour against it, and stating plainly which failures a given metric can and cannot detect.

We do not train foundation models and we do not sell a dashboard. We build instruments, and we publish the methodology so the measurements can be checked by the people relying on them.

Portfolio

Four lines, maturity stated

A capability statement that hides readiness wastes everyone's time, so each one says where it actually is.

Gauntlet

Built & measured

Behavioural evaluation for language-model agents. Places commercial models in instrumented multi-agent environments where the optimal outcome is computed exactly from assigned private values, so each agent is scored against a known optimum rather than a rubric. Two mechanisms; eleven models from eight developers run to date.

MiniCrit

Released · Apache 2.0

Adversarial validation of AI reasoning — an independent critic that challenges a model's output before an action is taken. Open source, available via Python SDK, MCP, Docker and REST.

Frontier

In development

Continuous authorisation and policy-audit automation for IL5/IL6 and FedRAMP High environments. Addresses enterprise data governance, policy enforcement and system-level reciprocity.

Banneret

Specification

Assurance for the agent configuration layer: a versioned schema for an agent's authorisation slice, a multi-model evaluation runner, and a repeatable evidence artifact an ISSO or authorising official can file.
