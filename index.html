Evidence about what AI systems actually do

Antagon builds instruments that produce checkable evidence: how a model behaves when scored against a computable optimum, whether a particular output should be acted on, and whether an authorising official can rely on either.

What we build Capabilities statement

From a Gauntlet measurement campaign

Eleven commercially available models from eight developers. Every one cleared a conventional 90% efficiency threshold.

Three of them finished worse than not participating at all.

An evaluation reporting the environment-level figure alone would have certified all eleven. That gap is the measurement problem we exist to close.

The problem we work on

A passing score is not the same as a finding

Most AI evaluation reports whether a system passed. That answers a different question from the one a programme office actually has.

The question is whether the reported number supports the conclusion being drawn from it. A metric that aggregates across an environment can look healthy while individual agents inside it destroy value, and no amount of precision in that number will reveal it.

Our work is measurement validity: building environments where the correct outcome is computed exactly rather than estimated, scoring behaviour against it, and stating plainly which failures a given metric can and cannot detect.

We do not train foundation models and we do not sell a dashboard. We build instruments, and we publish the methodology so the measurements can be checked by the people relying on them.

What we build

Four lines, maturity stated

A capability statement that hides readiness wastes everyone's time, so each one says where it actually is.

Gauntlet

Built & measured

Behavioural evaluation for language-model agents, scored against an optimum computed exactly from assigned private values rather than against a rubric. Task instances are generated procedurally per session by Antavault, our dataset layer, so there is no fixed item bank for a model to have memorised.

MiniCrit

Released · Apache 2.0

An independent critic that challenges a model's reasoning before an action is taken. Open source, self-hosted, available via Python SDK, MCP, Docker and REST. See how it works.

Banneret

Specification

Assurance for the agent configuration layer: a versioned schema for an agent's authorisation slice, and a repeatable evidence artifact an ISSO or authorising official can file.

Frontier

In development

The same evidence, produced continuously for authorisation rather than once for a package — policy-audit automation for IL5/IL6 and FedRAMP High environments.

Evidence

Measured, not asserted

Gauntlet is the line with results on the record. The environment is deterministic and seeded; reported figures regenerate from the released scripts.

Across eleven commercially available models from eight developers, the spread in environment-level efficiency was 2.5 percentage points — while the spread in what the individual agent captured, on the same runs, was 79 units. A metric reporting only the first would have found eleven near-identical systems where there were not eleven near-identical systems.

Methodology, figures and the federal registration detail are set out in full on the capabilities statement, and a paper on the decomposition behind this finding is under peer review.
